# Illunis

Lifestyle pattern-detection fitness app. Tracks health stats, journal, nutrition,
and strength training — then surfaces data-driven trends and advice.

- **Journal** — AI-assisted logging of activity, food, workouts
- **Dashboard** — live goal fulfillment + collected-data trends
- **Signature** — sun/moon procession 3D visualization as the app's living shell

Status: greenfield. Phase 1 (Cursor/Fable 5.1) = 3D UI shell. See `CURSOR_MANDATE.md`.
